# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [3.0] — 2026-10-24

### Добавлено
- Приложение Zapret в строке меню (`app/`, SwiftUI, собирается без Xcode через `app/build.sh`). Значок: ▶ зелёный — обход работает, ⏸ жёлтый — пауза (VPN или вручную), ■ красный — выключен. Панель вырастает из значка; главная кнопка подбирает стратегии и включает обход, повторное нажатие выключает; светлая и тёмная тема.
- Пауза с таймером: 15 минут, час или пока не снимешь (`pause МИНУТ`, `resume`).
- `strategies.conf` — стратегии tpws и utunws отдельным файлом. Кнопка «Обновить стратегии» и сторож раз в сутки скачивают его с GitHub вместе со списками Flowseal. Скрипт принимает только знакомые опции без путей к файлам, у tpws в каждом блоке обязателен `@HL`, а tpws и utunws должны принять каждую стратегию.
- 16 стратегий utunws для Discord из пресетов Flowseal (всего 19) и поддельные пакеты для них: `tls_clienthello_max_ru.bin`, `stun.bin`, `stun2.bin`.
- Стратегии для каждой сети: после подбора запоминаются по MAC шлюза и ставятся сразу, когда Mac снова в этой сети.
- Сторож замечает пробуждение Mac и сразу проверяет сеть и сайты; без интернета повторяет проверку через полминуты.
- Свои сайты: включаются и выключаются (`USER_SITES`), проверяются, для них есть отдельный подбор (`sites-select`). Приложение само находит домены, с которых сайт грузит картинки и скрипты.
- Команды для приложения: `on`, `off`, `info`, `check-now`, `update-strategies`, `sites`, `site-add`, `site-del`, `dns on|off`, `uninstall yes`, `gui-install`.
- Уведомления через приложение: о переподборе, о том, что сайты не открываются, об обновлениях. Само приложение обновляется из релизов GitHub.
- `tests/strategies.sh`, сборка приложения в CI.

### Исправлено
- Обход не работал, пока запущена виртуальная машина с общей сетью (UTM, Docker) или включён общий доступ к интернету: их правило `pass on en0 all flags any keep state` перекрывало перехват в tpws (программы шли напрямую) и уводило соединения Discord мимо utunws (любая стратегия давала 0 из 5). Перехват теперь `quick`, ответы для utunws пропускаются своим правилом без состояния.
- Перехват в tpws не работал после AmneziaVPN: подключаясь, она грузит в pf «set skip on lo0», и pf перестаёт обрабатывать lo0 вместе с нашим rdr; флаг остаётся и после отключения VPN. Служба снимает его при каждом включении перехвата и при сверке (загрузкой параметров pf без -m, правила не трогаются).
- Проверка перехвата при включении обманывалась старыми состояниями pf и считала сломанный перехват рабочим; теперь она ищет своё соединение по своему порту.
- DNS Google/Cloudflare: ТСПУ с августа 2026 года подделывает их ответы (youtube.com — «нет такого домена»). Включить их при подмене нельзя, а если они уже включены, сторож и приложение предупреждают.
- bash 3.2 под UTF-8 склеивал переменную с идущими следом «», … — сообщения выводились без подставленных значений.

### Изменено
- Настройки хранят названия стратегий, а не номера; номера из 2.x переводятся при установке.
- Стратегию, которая открыла всё, подбор проверяет второй раз и берёт меньший балл — на нестабильной сети случайная удача больше не сохраняется.
- Итог каждой проверки сторожа пишется в журнал, а не только сбои.

## [2.3] — 2026-10-21

### Добавлено
- Подбор стратегий utunws под текущую сеть. Для Discord — SEQOVL, FAKE и FAKESEQOVL из Flowseal: на мобильном интернете МегаФона простой поддельный пакет (FAKE) не работает, а SEQOVL работает и там, и у домашнего провайдера. Стратегии проверяет временный utunws на `utun51`, рабочий Discord при этом не трогается.
- YouTube через utunws (`hostfakesplit`) — если tpws на этой сети открывает YouTube не полностью. Подбор сам решает, через что пускать YouTube (`YT=tpws|utunws`).
- Ручной выбор стратегии utunws и способа обхода YouTube в пункте 3.
- Сторож при сбое подбирает заново и стратегии utunws.

### Изменено
- С utunws подбор tpws проверяет только YouTube: Discord через tpws не идёт, и его баллы только путали.
- Сервер обновлений Discord (`stable.dl2.discordapp.net`) идёт через utunws вместе с остальным Discord.
- Проверки считают открывшимся только то, что скачалось без ошибки; особые пометки для оборвавшихся соединений и уведомления о них убраны.
- Замеры стратегий перенесены в `docs/architecture.md`, отдельный документ про Discord убран.

## [2.2] — 2026-10-21

### Добавлено
- Второй движок для Discord — utunws из [Flowseal/zapret-mac-discord-youtube](https://github.com/Flowseal/zapret-mac-discord-youtube): nfqws, который получает пакеты через `utun` и отправляет через BPF. Стратегия `simple-fake`: поддельный ClientHello с `www.google.com` перед настоящим. Приложение Discord, чаты и голос по UDP идут через обход без VPN.
- LaunchDaemon `com.zapret-mac.utunws`, настройка «Discord через utunws» (пункт 9 → 5, `UTUNWS=1`).
- «Проверить» при включённом VPN показывает и Discord через utunws.
- utunws и поддельные пакеты скачиваются из релиза Flowseal, SHA-256 сверяется; `update` его переустанавливает при смене версии.

### Изменено
- Правила pf: адреса Discord (`162.159.128.0/21`, `162.159.136.0/22`) и порты голоса уходят в utunws, QUIC и IPv6 к Discord получают отказ.
- Сторож перезапускает utunws при смене сети и снимает его правила, если utunws не отвечает.
- `tests/dry-run.sh` и CI проверяют параметры utunws.

## [2.1] — 2026-10-21

### Добавлено
- Проверки отдельно помечали оборвавшиеся соединения (в 2.3 убрано).
- Исключения для служб Apple (`list-exclude-mac.txt`).
- Настройка «Автосписок» (пункт 9 → 4).
- `tests/dry-run.sh` и CI: tpws должен принимать все стратегии.

### Изменено
- Сторож не запускал подбор из-за оборвавшихся соединений (в 2.3 убрано).
- Автосписок tpws выключен по умолчанию: он принимал за блокировку обычные обрывы (например, `ocsp2.apple.com`) и начинал трогать сайты, которые и так работали.
- Проверка «YouTube: видео» качает 49 байт (`report_mapping?di=no`) вместо ~750 КБ отладочной информации.

## 2.0 — 2026-10-21

### Добавлено
- Прозрачный режим через pf, как в оригинальном zapret: обход видят все программы, включая апдейтер Discord.
- Отдельные стратегии для YouTube и для Discord.
- Сторож (LaunchDaemon): снимает перенаправление, пока включён VPN в режиме TUN, и возвращает, когда VPN выключен; проверяет сайты и сам подбирает стратегии.
- Подбор стратегий при включённом VPN.
- Блокировка QUIC к сервисам Google.
- Запасные варианты: якорь в `/etc/pf.conf`, затем режим SOCKS-прокси.
- Перенос настроек из первой версии.

### Исправлено
- Четыре стратегии (ALT, ALT7, ALT8, ALT10) не запускались: на macOS tpws не принимает `--oob` вместе с `--disorder`.
